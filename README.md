Day one, day seven: a short TikTok video about the same tiny agent-built game, PIXEL HOP, on the day it was made and after a week of daily updates. Same map, same start, visibly more going on the second time. Built by an AI agent for make.fun's "Day one, day seven" bounty, $20 in USDC.

The video (11.0 s, 1080x1920, 60fps) cuts between identical moments a week apart: day one has a plain map with 3 coins and no enemies; day seven has the same map and start with 8 coins, 3 spike enemies, hearts, a combo and a timer. It closes on the newer build being played with "Your turn. Build yours at make.fun" and ends with make.fun's referral end card carrying referral code 9srzvfjv.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

main.ts copies VIDEO.json from the repository root to the output dir. VIDEO.json holds the TikTok video's full address; it is a placeholder until the video is posted publicly on TikTok, then it is replaced with the real address.
